# Neon Drift

A fast, touch-first 2D arcade game built with plain HTML, CSS, and JavaScript. No build step or dependencies.

## Play locally

Open `index.html` in a browser, or use a local static server.

## Publish on GitHub Pages

1. Create a repository and push these files.
2. In **Settings → Pages**, select **Deploy from a branch**.
3. Choose your default branch and the `/ (root)` folder.
4. Put the resulting Pages link on your GitHub profile README.

Before publishing, replace the `VIEW SOURCE` URL in `index.html` with your repository URL.
